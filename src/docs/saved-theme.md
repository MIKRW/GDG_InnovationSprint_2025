# Saved Theme

This file contains the HSL values for a saved theme. You can use this to recall a theme if it gets replaced in a save slot.

## Default Theme

- **Words**: sand, stone, ocean
- **Mood**: warm

### HSL Color Values:

- **Background**: `hsl(39, 100%, 97%)`
- **Foreground**: `hsl(39, 50%, 10%)`
- **Primary**: `hsl(39, 50%, 20%)`
- **Ring**: `hsl(39, 50%, 30%)`
