### Project Overview

"Name that Bird" is an intelligent web application that uses generative AI to identify bird species from audio recordings. A primary goal of this project is to ensure the application is highly accessible to all users.

### Justification for Quota Increase

We are using the `gemini-2.5-flash-preview-tts` model as the engine for our core accessibility feature: **UI Audio Narration**. This system provides spoken descriptions of pages, UI elements, and analysis results, making the application navigable and usable for individuals with visual impairments.

The current quota of **1 request per minute** is unfortunately too restrictive to provide a functional user experience. For example, when a user navigates through their "Bird Book" (a carousel of saved results), they may wish to hear the description of several different entries in quick succession. The current limit prevents this, hindering the effectiveness of our accessibility implementation.

To ensure a smooth and accessible user experience during our development and testing phases, we are requesting an increase of our quota to **60 requests per minute**. This would allow for reasonable usage of the narration feature without hitting immediate limits.
