# Application Modes Feature List

This document outlines the features available in each application mode, providing a clear roadmap for development.

---

## Newbie Mode Features (Current)

This mode is designed for the general public, focusing on a simple and engaging user experience.

- **Standard Audio Recording**: Captures audio using the efficient and widely compatible WebM format.
- **AI-Powered Identification**: Utilizes a powerful AI model to identify bird species from audio recordings.
- **Location-Enhanced Analysis**: Optionally uses device GPS, a manual coordinate entry, or a text description of a location to improve identification accuracy by considering geographic habitats.
- **Privacy-Aware Mode**: Allows users to perform identifications without sending any location data to the AI.
- **Digital "Bird Book"**: Automatically saves all successful identifications into a browsable log, including a generated image, description, and the date of capture.
- **Mystery Recordings Log**: Saves any audio that the AI cannot confidently identify into a separate log, allowing the user to review it later.
- **AI Theme Generator**: Creates custom UI color schemes based on user-provided words and a selected mood.
- **Manual Theme Editor**: Provides granular control over the application's color palette with HSL sliders.

---

## Twitcher Mode Features (Planned Upgrades)

This mode is intended for researchers, professional ornithologists, and serious enthusiasts who require higher precision and more advanced tools.

- **High-Fidelity Audio**: Will support recording and processing in lossless formats like `.wav` to provide the AI with the maximum possible data for analysis.
- **Advanced Spectrogram Analysis**: Planned tools to visualize the audio spectrogram directly within the app.
- **Batch Processing**: Future capability to upload and analyze multiple audio files at once.
- **Detailed Data Export**: Options to export identification data, including location, time, and audio metadata, in formats suitable for research (e.g., CSV).
- **Advanced Identification Controls**: Potential for features that allow for manual selection of AI models or sensitivity adjustments.
- **Offline Field Guides**: Plans to integrate offline regional bird guides.
