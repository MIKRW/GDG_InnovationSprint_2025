# Name that Bird

Name that Bird is an intelligent, modern web application designed to identify bird species from audio recordings using the power of generative AI. It offers a seamless user experience, allowing users to capture bird songs and receive detailed information about the identified species. The application features a customizable interface and is built with a focus on accessibility.

---

## Key Features

-   **Live Audio Recording**: Capture bird songs in real-time directly through the browser using a high-fidelity, client-side WAV encoding system.
-   **AI-Powered Identification**: Utilizes Google's Gemini family of models via Genkit to analyze audio recordings. The AI considers the audio, geographical location, and time of year to provide an accurate identification.
-   **Dynamic Results Display**: View detailed results for each identification, including the bird's common and scientific names, an AI-generated image, and interesting facts.
-   **"Bird Book" Personal Log**: Save successful identifications to a personal, swipeable log. The log is stored locally and includes an AI assistant for searching and sorting entries.
-   **AI Theme Generator**: Customize the application's entire user interface by generating color palettes from descriptive words (e.g., "forest, creek, sunset") and a selected mood. A manual editor is also available for fine-tuning.
-   **Accessible UI with Audio Narration**: Key pages and actions include descriptive audio narration, generated by a Text-to-Speech AI, to guide users. This feature can be toggled on or off.

---

## Tech Stack

-   **Framework**: Next.js (App Router)
-   **Language**: TypeScript
-   **AI/ML**: Google's Gemini models (Gemini 2.5 Flash, Imagen 4) via Genkit
-   **UI Components**: ShadCN UI
-   **Styling**: Tailwind CSS
-   **Database**: Firestore (for logging errors and future data storage)
-   **Storage**: Firebase Storage (for audio recordings)
-   **Deployment**: Firebase App Hosting

---

## Recent Development Focus

Recent work has focused heavily on improving the robustness and user experience of the application's AI and audio features.

-   **Resilient AI Flows**: The core AI identification and Text-to-Speech (TTS) flows have been refactored to gracefully handle potential backend and API quota errors. Instead of crashing, the app now provides clear feedback to the user and logs errors to Firestore for debugging.
-   **Audio Narration System**: Implemented a comprehensive audio narration system using a custom `useSpeaker` hook. This system now correctly plays static `.mp3` files for UI narration, resolving previous bugs related to audio playback and providing a more accessible user experience.
-   **High-Fidelity Recording**: The audio recording functionality was upgraded from the standard `MediaRecorder` to a more robust system using `AudioWorklet` and a custom WAV encoder. This ensures that the AI receives high-quality, uncompressed audio data for analysis, improving identification accuracy.
